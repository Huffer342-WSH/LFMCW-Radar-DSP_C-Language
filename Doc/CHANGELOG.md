## [0.3.0] - 2025-04-26

### 目标跟踪部分基本功能已经完成

目标跟踪部分对外接口：
```c
void tracker_run(tracker_handel_t *tracker_handel, \
                 tracked_targets_list_t *tracked_targets, \
                 tracked_targets_list_t *unconfirmed_targets, \
                 size_t meas_num, \
                 uint32_t timestamp_ms, \
                 set_meas_callback cb,  \
                 void *args \
)
```
输入新的一帧测量值，并维护两个目标列表：为确认目标、已跟踪目标。通过回调函数的方式将测量值传递到跟踪器内，以兼容不同环境

### 项目的文件结构变化

将信号处理、目标跟踪、应用三个部分的代码解耦并放到了不同的文件夹内
